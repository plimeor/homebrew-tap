# Plimeor Tap

## How do I install these formulae?

`brew install plimeor/tap/<formula>`

Or `brew tap plimeor/tap` and then `brew install <formula>`.

Or, in a `brew bundle` `Brewfile`:

```ruby
tap "plimeor/tap"
brew "<formula>"
```

## Documentation

`brew help`, `man brew` or check [Homebrew's documentation](https://docs.brew.sh).
